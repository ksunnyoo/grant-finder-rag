외부 서비스·모델을 실제로 실행한 결과만 일시와 함께 기록한다. 실행하지 않은 항목의 수치는 쓰지 않는다.

## 실험 기록 (E-001 ~ E-018, 2026-11-06 ~ 11-10)

환경: Mac M3 / 메모리 16GB, Python 3.11, qdrant-client 1.20.0, Ollama(bge-m3, qwen3:8b)

### E-001. Qdrant 로컬 모드의 sparse + RRF + 필터 (PRD Q1)
- 스크립트: `scripts/probe_qdrant.py`
- 방법: `:memory:` 모드, dense(4차원) + sparse 벡터 4건, 지역 필터(서울, 전국) 적용 후 RRF 결합

- 한계: 파일 모드(`qdrant_data/`)는 확인하지 않음. 11/10 색인 단계에서 확인 예정

### E-002. bge-m3 임베딩 속도 (PRD Q3)
- 스크립트: `scripts/probe_embed_speed.py`
- 방법: 공고 `page_001`의 첫 64건(제목 + 본문 + 신청 대상 내용, 최대 2,000자), 배치 16건, Ollama `/api/embed`

- 예상(위 값 기준 단순 환산): 7,369건 약 10.3분, 3,530건 약 4.9분
- 한계: 실제 검색 문서는 사업 소개와 신청 방법이 추가되어 더 길어짐. 11/10 실제 색인에서 재측정 예정
- 결론: 색인 범위는 접수 시작일 2025-01-01 이후 7,369건으로 한다 (SDD 4.3절)

### E-004. 검색 동작·시간 확인 (PRD 2-2, 2026-11-09)
- 명령: `python -m grant_finder_rag.cli search "서울 예비창업자 지원사업" --mode {dense|hybrid} [--no-rerank]`
- 방법: 질문 1개, 구성별 1회 실행. 필터 미적용. 정확도 평가가 아니라 동작과 시간 확인이다
- 결과: dense 2,753ms(첫 실행), hybrid 1,047ms, hybrid+리랭커는 검색 1,102ms + 리랭크 4,087ms(후보 20건). 세 구성의 1위는 같고 3~5위는 다름
- 관찰: 리랭커 점수가 상위 5건 모두 0.992~0.997. 마감된 공고와 지역이 다른 공고가 섞여 나옴(필터는 2-3)
- 한계: 1회 측정이고 리랭커는 첫 실행의 모델 로딩 시간이 포함될 수 있다. 정확도 비교는 4-2 골든셋 평가에서 한다
- 결론: 리랭커 처리 시간은 질문당 30초 목표 안에 들어간다 (PRD Q4)

### E-005. 조건 필터 동작 확인 (PRD 2-3, 2026-11-09)
- 명령: `python -m grant_finder_rag.cli search "<질문>"` (기준일 2026-11-06, hybrid + 리랭커, 필터 자동 추출)
- 질문 3개: "서울 예비창업자 지원사업", "이번 달 마감인 창업교육 공고는?", "만 35세, 창업 2년차가 신청 가능한 사업은?"
- 결과: 세 질문 모두 의도한 조건이 추출되었다. 1번은 상위 5건이 모두 서울이고 마감이 기준일 이후, 2번은 상위 5건이 모두 창업교육이고 마감이 11-06~11-30 안이었다. 3번은 조건(나이 35, 2년미만)만 확인했고 충족 여부는 4-1에서 측정한다
- 관찰: 리랭커 점수가 1번 0.97~0.99, 2번 0.09~0.22, 3번 약 0.02로 질문에 따라 크게 다르다. 조건 중심 질문은 의미 내용이 적어 점수가 낮으므로, 리랭커 점수만으로 거절하면 정상 질문을 거절할 수 있다
- 시간: 검색 1.1~2.9초, 리랭크 2.4~4.4초 (각 1회)
- 한계: 질문 3개, 1회 측정. 공고별 조건 충족 여부와 정확도는 4-1·4-2에서 측정한다

### E-006. 거절 기준 점수 측정 (PRD 3-2, Q6, 2026-11-09)
- 스크립트: `scripts/probe_refusal.py` (질문 16개: 답변 가능 8, 불가 8. hybrid + 리랭커, 필터 자동 추출, 기준일 2026-11-06)
- 라벨은 작성자의 가정이며 데이터로 검증하지 않았다. 정식 라벨은 4-1 골든셋에서 확정한다
- 리랭커 최고점: 조건 없는 답변 가능 질문 4개는 0.987, 0.964, 0.961, 0.223. 조건이 추출된 답변 가능 질문 4개는 0.999, 0.682, 0.443, 0.035. 답변 불가 질문 8개는 0.000~0.005 (이 중 1개는 조건이 추출됨)
- 결정: 조건이 없는 질문에만 점수 기준을 적용하고 잠정 `REFUSE_THRESHOLD=0.05`로 한다 (조건 없는 답변 가능 최저 0.223과 답변 불가 최고 0.005 사이). 조건이 추출된 질문은 정상이어도 점수가 낮을 수 있어(0.035) 점수 기준을 적용하지 않고 LLM 판단에 맡긴다
- 한계: 표본 16개, 라벨 미검증. 4-1 골든셋의 거절 정확도·오거절률로 재검증한다

### E-008. 골든셋 평가 (PRD 4-1, 4-2, 2026-11-09)
- 골든셋: `data/golden/golden.jsonl` 50문항 (lookup 15, filter 15, date 8, multi 4, no_answer 8). 정답은 `scripts/build_golden.py`가 정제 데이터에서 계산했다. 기준일 2026-11-06, 마감 전 공고 214건. 실행: `scripts/run_eval.py`, 결과: `data/eval/`
- 검색 구성 비교 (LLM 없음, 상위 5개, 2회 실행해 동일 결과)

|---|---|---|---|---|---|---|
| C0 dense | 1.00 | 0.84 | 0.08 | 0.08 | 0.00 | 33 |
| C1 +hybrid | 1.00 | 0.83 | 0.07 | 0.08 | 0.00 | 133 |
| C2 +filter | 0.93 | 0.93 | 1.00 | 1.00 | 1.00 | 208 |
| C3 +rerank | 0.93 | 0.93 | 1.00 | 1.00 | 1.00 | 3,038 |

- 종단 평가 (LLM 사용, 35문항 표본: no_answer 8, lookup 15, 그 외 12): 거절 정확도 8/8, 오거절률 1/27, 인용 비율 26/26, lookup 정답이 출처에 포함된 비율 14/15. 거절 사유는 모두 LOW_RELEVANCE였다
- 해석: 필터는 정밀도를 0.08에서 1.00으로 올리고 MRR을 0.84에서 0.93으로 올렸다. hybrid와 리랭커의 효과는 이 골든셋으로 구분되지 않았다 (C2와 C3 동일, 지연만 0.2초에서 3초)
- 한계: lookup 질문이 제목을 거의 그대로 써서 쉽다. 검색 대상이 마감 전 214건뿐이다. filter/date/multi의 정답은 시스템과 같은 조건 해석(전국 포함, 대상 미기재 통과)으로 계산했으므로 조건 준수만 보여 주고 검색 품질을 증명하지 않는다. no_answer 8개 중 7개는 주제가 완전히 다른 쉬운 질문이다. 인용 비율은 형식(출처 존재)만 보며 답변 정확성은 측정하지 않았다. 종단 평가는 1회 실행, 표본이 작아 오거절 1건 = 3.7%p이다
- 후속: lookup 오답(G012)의 원인(분야 오탐)은 E-009에서 고쳤고, 수정 후 수치는 E-009와 E-013을 따른다

### E-009. 분야 자동 추출 해제 후 재평가 (PRD 4-2, 2026-11-09)
- 원인: E-008의 lookup G012가 질문 속 "글로벌"이 category 필터가 되어 정답 공고를 제외했다. 거절은 남은 1건이 무관해서 LLM이 근거 없음으로 판단한 결과다
- 조치: analyze_query의 분야 자동 추출 기본값을 끔 (extract_category=False). 분야는 화면 조건 선택으로만 지정한다. 지역, 업력, 마감 시기 추출은 유지
- 재평가 (LLM 없음, 상위 5개): C2와 C3 모두 Hit@5 1.00, MRR 1.00, 정밀도 1.00. C0와 C1은 변화 없음
- 한계: 종단 평가(LLM)는 다시 돌리지 않았다. 골든셋을 보고 원인을 찾아 고쳤으므로 이 골든셋의 개선 수치는 낙관적이다. 분야를 말로 해도 필터가 걸리지 않는 영향은 측정하지 않았다

### E-010. 어려운 골든셋 평가 (PRD 4-2, 2026-11-09)
- 골든셋: `data/golden/golden_hard.jsonl` 15문항 (기관+분야형 8, 본문 희귀 단어형 7). 제목을 질문에 쓰지 않았고, 정답은 `scripts/build_golden_hard.py`가 마감 전 공고 214건에서 계산했다. 실행: `scripts/run_eval.py --skip-e2e --golden data/golden/golden_hard.jsonl` (LLM 없음, 상위 5개)

| 구성 | Hit@5 | MRR | 중앙 지연(ms) |
|---|---|---|---|
| C0 dense | 0.47 | 0.20 | 36 |
| C1 +hybrid | 0.47 | 0.32 | 137 |
| C2 +filter | 0.87 | 0.79 | 198 |
| C3 +rerank | 0.93 | 0.85 | 3,144 |

- 해석: hybrid는 Hit@5를 올리지 못했고 MRR만 올렸다. 필터가 가장 크게 올렸다. 리랭커는 1문항을 더 맞혔다
- 한계: 15문항이라 1문항이 6.7%p이다. 리랭커의 개선은 우연과 구분되지 않는다. 정답이 마감 전 공고만 대상인데 필터 없는 구성은 마감 공고까지 검색하므로 필터의 개선 폭에는 마감 공고 제외 규칙 자체의 효과가 섞여 있다. 질문이 템플릿으로 만들어져 자연스럽지 않다. 놓친 문항의 원인은 아직 분석하지 않았다

- E-010 유형별 (맞힌 문항 수): 기관+분야형 8문항은 C0 5, C1 5, C2 8, C3 8. 희귀 단어형 7문항은 C0 2, C1 2, C2 5, C3 6. C3가 놓친 1문항은 H011("되어있는, 중소기업과의 관련 공고")이다
- E-010 해석 정정: 희귀 단어형 질문은 조사가 붙은 어형이 본문에 한 번만 나온 단어를 골랐다. 형태소 분석 후에는 흔한 단어가 되어 희귀하지 않다. 그래서 hybrid(BM25)의 효과를 시험하지 못했다. "hybrid가 효과 없다"가 아니라 "이 골든셋으로는 효과를 확인하지 못했다"로 해석한다. 개선하려면 형태소 분석 후 문서 빈도가 낮은 명사(고유명사, 사업명)로 질문을 만들어야 한다

### E-019. 짧은 주제 질문의 요청 어미 제거 (2026-11-11 11:30)

- 목적: E-017에서 확인한 "짧은 주제 질문이 점수로 잘못 거절되는 문제"를 줄이는 방법을 측정하고, 효과가 있으면 적용합니다. 설계는 SDD 5.1.1에 먼저 적었습니다.
- 방법: 마감 전 색인 문서 213건(기준일 2026-11-06)의 제목과 본문에서 주제어 32개의 포함 건수를 세어, 3건 이상은 "답변 가능(A)", 0건은 "답변 불가(U)", 1~2건은 제외했습니다(A 19개, U 6개). 같은 주제를 두 모양으로 전체 흐름(검색, 리랭크, 점수 판단, LLM, 출처 확인)에 넣었습니다. T1은 현재 방식 "X 지원사업 알려줘", T2는 요청 어미를 뗀 "X 지원사업"입니다.
- 결과

| | T1 (알려줘 포함) | T2 (어미 제거) |
|---|---|---|
| 답변 가능 19개 | 답변 11, 점수로 거절 8 | 답변 18, LLM이 거절 1 |
| 답변 불가 6개 | 점수로 거절 5, 답변 1 | LLM이 거절 3, 점수로 거절 1, 답변 2 |

- 해석
  - T1의 점수 거절 8건에는 색인 문서가 14건인 "바이오", 11건인 "환경"처럼 관련 공고가 있는 주제가 포함됩니다. T2에서는 이 주제들이 답변되었습니다.
  - T2에서 점수를 통과한 범위 밖 질문(패션, 소셜벤처, 연예)은 LLM이 거절했습니다.
  - 답변 불가 중 답변된 2건은 "농업"(`청년농산업 창업지원센터 보육생 모집`)과 "요리"(`키친인큐베이터·공유주방` 공고)입니다. 내용을 확인하지는 않았지만 주제와 관련 있어 보여, 오답이 아니라 라벨(본문에 단어가 없으면 답변 불가)의 오류일 수 있습니다. "주식"에서 LLM이 거절한 1건은 "주식회사"에 걸린 라벨 오류일 수 있습니다.
- 적용: 조건이 추출·선택되지 않은 질문 중, 요청 어미를 뗀 결과가 15자 이하인 질문만 어미를 떼어 검색·리랭크에 씁니다(`search_query()`). 조건 추출과 LLM에 전달하는 질문은 원문입니다. 단위 테스트 12개를 추가했고 전체 테스트는 88개 통과했습니다.
- 규칙을 "조건 없는 질문"으로 좁힌 이유: 처음에는 조건 유무와 관계없이 적용했습니다. 이 상태에서 골든셋 종단 평가(35문항)를 돌린 결과는 거절 정확도 8/8, 오거절 2/27(E-013은 1/27), 출처 인용 25/25, 정답 공고 포함 14/15였습니다. 오거절 2건을 확인했습니다.
  - G015(`전문분야 창업멘토링 11월 지원 내용이 뭐야?`)는 어미 제거 대상이 아니었습니다. 같은 후보(최고점 0.963)로 LLM을 3번씩 돌리자 1/3과 3/3이 거절되어, LLM 응답의 변동으로 보입니다.
  - G032(`다음 달 마감되는 사업 알려줘`)는 어미를 떼자 후보가 바뀌었고 LLM 거절이 1/3에서 2/3로 늘었습니다. 시행이 3번이라 변동일 수도 있으나, 점수 거절은 조건이 없을 때만 쓰이므로 조건이 있는 질문에는 어미 제거의 이점이 없다고 보고 제외했습니다.
- 희귀어 조회 골든셋(15문항 중 어미가 떼지는 5문항)의 검색 비교(LLM 없음): 최종 구성(C3 +rerank)은 Hit@5 0.87, MRR 0.82로 어미 제거 전후가 같았습니다. 리랭크 전 구성은 C1 +hybrid의 MRR이 0.46에서 0.52, F-dense의 Hit@5가 0.53에서 0.60이었습니다.
- 범위 밖 질문: 종단 평가에서 어미가 떼진 5문항(비트코인 시세, 삼성전자 채용, 아파트 청약, 강남 맛집, 파이썬 설치)이 모두 `LOW_RELEVANCE`로 거절되어 8/8을 유지했습니다.
- 한계
  - 주제어 25개의 작은 측정이고 라벨은 키워드 기반이라 오류가 있을 수 있습니다.
  - 좁힌 규칙 그대로의 종단 평가는 다시 돌리지 않았습니다. 좁히기 전 실행에서 조건 없는 범위 밖 질문 5개는 어미가 떼진 상태로 모두 거절되었고, 좁힌 뒤에도 같은 질문이므로 결과는 같다고 봅니다.
  - 짧은 주제 질문의 개선 폭은 검색기를 직접 호출해 측정했고, `ask()` 경로의 짧은 주제 질문은 별도 평가가 없습니다.
